# Graphic Deliverables And Production

Design for the real viewing and production conditions. Current vendor or platform specifications override remembered defaults.

## Deliverable Dispatch

| Deliverable | Design priorities | Required checks |
| --- | --- | --- |
| Campaign / key visual | One proposition, message ladder, recognizable system, adaptable crop, CTA/proof | Works without every element; channel variants remain one campaign; claims are sourced |
| Poster / outdoor | Viewing distance, dwell time, dominant read, environment, scale | Distance/thumbnail test, real-size type, glare/lighting, installation and trim |
| Social / display | Fast recognition, crop/safe area, thumbnail, platform overlays, captions | Fetch current official specs; preview in placement; test auto-crop, compression, dark/light surroundings |
| Editorial / report | Page architecture, navigation, type rhythm, image/caption system, tables/charts | Long-content stress test, TOC/folios, widows/orphans, footnotes, links, print and accessible digital output |
| Infographic / data graphic | Question, source, measure, unit, timeframe, comparison, uncertainty | Truthful scale, direct labels, non-color path, source note, text/table alternative |
| Packaging / label | Shelf/e-commerce hierarchy, panel sequence, product truth, dieline, substrate | Printer dieline, mandatory copy, barcode/QR verification, folds/seams, proof and physical mockup |
| Signage / wayfinding | Decision points, distance, approach, language, lighting, material | Location plan, legibility distance, arrows/map consistency, contrast, fabrication and accessibility |
| Stationery / template | Variable content, editability, ordinary-user resilience, office output | Long names/data, fallback fonts, protected regions, common printer/software, locked styles |
| Presentation / event | Story sequence, screen/room, presenter behavior, brand recognition | Projector contrast, back-row legibility, safe areas, media playback, static fallback |
| Merchandise / specialty | Object shape, process, limited colors, durability, cultural context | Vendor template, seam/embroidery limits, minimum line/detail, sample and rights |

## Format And Module Stress Test

For each deliverable family, define the invariant message order and brand anchors, then define what may reflow, crop, disappear or move. Reusable modules need required/optional fields, content limits, image focal/safe areas, editable and protected regions, missing-content behavior, and named variants. A format adaptation is a new composition when reading distance, aspect, panel, platform overlay or production process changes the hierarchy; do not scale one master mechanically.

Test one normal artifact and one adversarial case with long Chinese-English text, large/small values, missing imagery, alternate logo lockup, constrained crop, and the least capable expected software or output process. When the module fails, simplify content, change span/layout, or use a documented alternate before shrinking essential type or breaking protected regions.

## Digital Production

- Obtain current official canvas, aspect ratio, crop, safe-zone, duration, codec, file-size, transparency, and text-overlay rules for the target platform. Do not freeze social dimensions in the skill.
- Keep important text, logos, faces, and actions inside verified safe areas; preview with real platform chrome, captions, and auto-crops.
- Default ordinary web graphics to the project's color-management policy and commonly supported output; embed the required profile when the workflow calls for it.
- Export at the actual display sizes and densities. Inspect compression, gradients, thin lines, small type, transparency, animation loop, first frame, and fallback image.
- Prefer live text for accessible digital documents and interfaces. When text must be an image, preserve an equivalent text alternative and a high-resolution source.
- Supply alt text/caption guidance, meaningful filenames, and reduced-motion/static alternatives where applicable.

## Print And Prepress

Ask the printer or fabricator for the production specification before final art. Record:

- trim, bleed, safe area, folds, binding, imposition responsibility, marks and slug;
- substrate, process, ink/spot colors, finishes, trapping/overprint, minimum line/type, total ink and black handling;
- target ICC/output condition, proof method, accepted PDF/X flavor and preflight profile;
- image effective resolution, transparency, font embedding/outlining, dieline layers and naming;
- quantity, tolerances, finishing, delivery packaging and sustainability constraints.

Do not assume `3 mm` bleed, a particular CMYK profile, rich-black recipe, crop marks, or PDF/X preset is universal. The vendor specification wins.

Before delivery:

1. update links and verify licenses/embedding rights;
2. inspect separations, spot names, overprint, knockout, transparency, black text, and total ink where relevant;
3. check TrimBox/BleedBox, dielines, safe content, image resolution, missing glyphs, and page count;
4. export the requested PDF/X or native package with the correct output intent;
5. run preflight, inspect the exported PDF at high zoom and whole-page view, and approve an appropriate soft/hard proof;
6. package source, linked assets, permitted fonts, presets, final output, and a manifest.

## Packaging And Barcodes

- Treat the supplied dieline as production geometry. Keep cut, fold, glue, seal, window, varnish, foil, emboss, white-ink, and variable-data layers separate and named to the vendor convention.
- Build a panel hierarchy for brand, product, variant, amount, key benefit, required information, instructions, warnings, ingredients, recycling and legal content. Product/regulatory owners approve mandatory copy.
- Generate barcodes/QR codes from authoritative data and the correct standard. Preserve quiet zones, contrast, module size, placement and human-readable text; do not stylize beyond the standard.
- Verify codes in final artwork and on a representative physical sample with appropriate scanners. Visual resemblance is not verification.
- Test shelf distance, e-commerce thumbnail, variant differentiation, curved/flexible surfaces, seams, glare, material color and production tolerance.

## Signage And Environmental Graphics

- Start from journeys and decision points, not individual signs. Define destinations, terminology, hierarchy, arrow/map grammar and bilingual order.
- Calculate legibility from viewing distance, speed, angle, lighting and obstruction. Verify on-site or in a dimensionally faithful simulation.
- Coordinate structure, mounting, material, fire/building/accessibility requirements, power, maintenance, weather and vandal resistance with qualified partners.
- Produce a location schedule, message schedule, elevation/dimension drawings, artwork, material/color specification and installation checks as required.

## Source And Export Package

Deliver only useful files, clearly separated:

- editable masters with organized layers, named styles/swatches, linked assets and correct artboards/pages;
- final vector assets such as SVG/PDF/EPS where required;
- final raster assets such as PNG/JPEG/WebP/TIFF at requested size, density, transparency and profile;
- print-ready PDFs and packaged sources when authorized;
- preview/contact sheet and a manifest listing purpose, dimensions, color space, version and restrictions.

Do not outline all type by habit; keep editable masters and outline only when the production workflow requires it and licensing permits. Do not deliver dozens of unexplained exports.

## Proofing And Acceptance

Review at three scales:

- **overview:** message hierarchy, balance, recognition and consistency;
- **actual use:** reading distance/size, crop, platform chrome, page sequence, shelf or environmental context;
- **detail:** kerning, alignment, curves, line quality, image artifacts, separations, legal copy and metadata.

Use representative content and worst cases, not only a perfect mockup. A mockup demonstrates context; it does not prove production readiness.
