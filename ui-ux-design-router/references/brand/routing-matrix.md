# Brand And Graphic Routing Matrix

Choose the mode from the communication job and final medium, not from a visual trend. A project may use one primary mode and one supporting mode; more branches require a real deliverable dependency.

Review, audit, scoring, acceptance, and version comparison are evaluation lenses, not design modes. First select the actual mode and system depth below. When the user explicitly requests one of those evaluation tasks, run `quality-gates.md` before `review-scorecard.md`; otherwise apply the gates during creation without producing a score.

## Mode Selection

| Mode | Strong signals | Required depth | Read next | Do not confuse with |
| --- | --- | --- | --- | --- |
| Brand strategy | New organization, repositioning, merger, portfolio confusion, naming, inconsistent promise | Audience/category research, positioning, proof, personality, architecture, verbal principles, measurement | `brand-system.md` | A logo refresh or moodboard |
| Visual identity / logo | New mark, rebrand, identity system, brand guidelines, co-branding | Strategy minimum, concept criteria, logo/lockups, type, color, graphic language, representative touchpoints | `brand-system.md`, then `graphic-production.md` for applications | A generic icon plus product name |
| Campaign / key visual | Launch, event, recruitment, promotion, awareness, multi-channel message | One proposition, message ladder, key visual system, CTA, channel adaptation, content/claim proof | `graphic-production.md` | A permanent identity redesign |
| Poster / social / digital graphic | Single communication artifact or content series | Reading order, format/safe zones, type/image hierarchy, accessibility, export variants | `graphic-production.md` | Product UI or a platform screenshot |
| Editorial / report / publication | Long-form reading, annual report, brochure, catalog, manual, book, PDF | Page architecture, grid, type system, navigation, tables/charts, pagination, print/digital outputs | `graphic-production.md` | A set of unrelated decorated pages |
| Packaging / label | Physical product, shelf/e-commerce view, regulatory content, barcode, dieline | Brand hierarchy, panel architecture, substrate/print process, dieline, legal copy, barcode verification, proof | `brand-system.md`, `graphic-production.md` | A photorealistic mockup without production art |
| Signage / environmental / event | Wayfinding, booth, venue, retail, large format | Distance, approach angle, hierarchy, contrast, material, fabrication, accessibility, location plan | `graphic-production.md` | A scaled-up poster |
| Icon / pictogram / illustration system | Custom symbolic language, category set, diagram style, brand illustration | Semantic inventory, family grammar, master grid, optical rules, cultural review, size tests, source masters | `visual-foundations.md`, `brand-system.md` | Logo, emoji, or decorative clip art |
| Template / governance system | Repeated internal/external production, many contributors, drift | Tokens/rules, editable templates, content limits, asset library, ownership, versioning, review workflow | `brand-system.md`, `graphic-production.md` | A static guideline PDF nobody can use |

## System Depth

- **Artifact:** one bounded output using an existing system. Do not redesign the identity.
- **Campaign family:** one message system across several formats for a defined lifespan.
- **Identity system:** strategy plus reusable visual/verbal assets and representative touchpoints.
- **Governed brand system:** identity plus architecture, templates, asset management, ownership, exceptions, and measurement.

Choose the smallest depth that covers the requested decisions. A single poster does not justify a new brand; a rebrand is not complete with a logo file.

## Route Inputs

Capture only inputs that can change the design:

- audience, context, viewing distance/duration, language, literacy, accessibility needs;
- message hierarchy, desired response, mandatory copy, claims and proof;
- existing equity, approved assets, competitors and category conventions;
- channels, sizes, variants, lifespan, editability, owners and approval path;
- budget, schedule, print/fabrication/vendor limits, platform specs and distribution;
- rights, trademark, privacy, representation, legal and sustainability constraints.

## Conflict Rules

Use this priority when inputs disagree:

1. Safety, law, accessibility, truth, rights, and production requirements.
2. Explicit user objective, audience, message, existing equity, and approved brand rules.
3. Medium and context: reading distance, platform behavior, substrate, print process, language.
4. Concept criteria and coherent system rules.
5. External references and aesthetic preference.

A lower-priority reference may inspire a treatment but cannot override a higher-priority constraint.

## Stop Conditions

Stop and ask one focused question when:

- stakeholders disagree on audience, proposition, brand ownership, or approval authority;
- mandatory claims, legal copy, product data, barcode data, dieline, or printer specification is missing;
- the requested resemblance risks copying a protected identity or confusing customers;
- a proposed name or mark is treated as legally cleared without a jurisdictional search;
- final dimensions, channel, or editability would materially change the composition or file type.
