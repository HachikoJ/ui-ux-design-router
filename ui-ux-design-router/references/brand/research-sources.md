# Evidence And Source Routing

Use the smallest authoritative source that answers the current question. Keep the rule locally only when it is stable and changes recurring decisions; fetch current platform, legal, vendor and production specifications when needed.

## Live Lookup Rules

- Fetch current official platform dimensions, safe zones, crop behavior, codecs and ad rules at production time. Third-party social-size roundups are discovery aids only.
- Obtain the actual printer, fabricator, packaging, signage or embroidery specification. Generic bleed, CMYK, resolution and PDF presets are not authoritative for a particular job.
- Use current trademark registries for preliminary search and qualified counsel for legal conclusions.
- Use official brand packages for existing logos, colors, type and co-branding. Skip login walls and never reconstruct blocked rules from memory.

## Case And Gallery Boundary

Use brand galleries, award sites, design archives and case studies to widen concept exploration or compare category conventions. They can show composition and craft, but cannot prove effectiveness, accessibility, rights, production correctness or fit for the target audience.

For any external reference that changes the design, record:

1. question and source;
2. observed fact;
3. what cannot be inferred;
4. project-specific rule or hypothesis;
5. how it will be tested;
6. what must not be copied.

Stop researching when the brief has one supported direction, the relevant risks are covered, and the next useful action is concept development or testing.
